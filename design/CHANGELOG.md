# Historique de la charte graphique

Format : [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/),
versionnement sémantique (voir `docs/08_design/evolution.md`).

## [1.0.0] — 2026-11-12

### Ajouté

- Identité : symbole toit + règle graduée, logotype horizontal, versions
  inversée et monochrome, favicon.
- Couleurs : gammes Ardoise (primaire), Cuivre (accent), Pierre (neutres),
  couleurs d'état, palette catégorielle de data-visualisation.
- Typographie : Plus Jakarta Sans (titres), Inter (texte), IBM Plex Mono
  (données) ; échelle 1,25 sur base 16 px.
- Tokens d'espacement (grille 4 px), rayons, ombres, durées, courbe
  d'animation.
- Thèmes sémantiques clair et sombre (dont couleurs d'état par thème), contrastes WCAG AA vérifiés.
- Application au site de documentation Zensical.
